Import people from CSV

Choose a UTF-8 CSV file, then map its columns. First name, last name and department are required. Existing matches are skipped.

Example CSV layout:

FirstName,LastName,Department,Title,Manager,Cell,Fax,Email,Location,URL,Description,Enabled
Tim,Digital,Support,Technician,,0211234567,,tim@example.com,Auckland,https://example.com,,true
Alex,Example,Sales,Manager,,,,alex@example.com,Auckland,,,true

Photos must be uploaded manually after import by editing each person.

Map CSV columns
